Travlr Getaways Application

Software Design & Engineering Enhancement

Artifact Narrative

This artifact is a full-stack travel booking application designed using the MEAN stack (MongoDB, Express, Angular, Node.js). It demonstrates key software engineering concepts, including modular application structure, RESTful API communication, authentication, and database integration.

Existing Functionality

The application provides a customer-facing travel browsing interface and an administrative single-page application for managing trip data. The backend uses Express to expose RESTful API endpoints connected to a MongoDB database using Mongoose. The Angular frontend consumes these APIs through reusable services and components. Authentication is implemented using JWT to restrict access to protected administrative routes and CRUD operations.

Areas for Improvement

While the application is functional and well-structured, it lacks role-based access control, limiting scalability for multiple user types. Input validation is partially distributed between the frontend and backend layers, reducing maintainability and consistency. Additionally, error handling is not fully centralized, which introduces code duplication across services and routes.

Planned Enhancements

Planned improvements include implementing role-based authentication using JWT claims and Express middleware, centralizing validation logic, and improving defensive programming practices. These enhancements improve security, scalability, and maintainability while aligning with professional software engineering standards.

Enhancements Implemented

  • Implemented structured modular MEAN stack architecture
  • Strengthened authentication using JWT-based route protection
  • Improved separation of concerns between frontend and backend services

Skills Demonstrated

  • Full-stack software engineering (MEAN stack)
  • RESTful API design and integration
  • Authentication and secure route handling
  • Modular application architecture
  • Code analysis and refactoring
