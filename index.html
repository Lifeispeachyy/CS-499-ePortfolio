Professional Self-Assessment

Completing the Computer Science program and developing this ePortfolio has significantly strengthened my technical, analytical, and professional skills across multiple domains of software development. Through structured coursework and hands-on project development, I gained practical experience in software engineering, algorithms and data structures, database systems, and secure coding practices.

In software engineering, I developed the ability to design modular, maintainable, and scalable applications. I learned how to evaluate existing systems for structural weaknesses and apply targeted enhancements to improve readability, maintainability, and system organization. My Travlr Getaways artifact demonstrates these skills through improvements in application structure and overall system design.

In algorithms and data structures, I strengthened my understanding of computational efficiency and problem-solving strategies. I learned to analyze time and space complexity and recognize how implementation choices affect performance. This allowed me to improve logic flow and reduce inefficiencies in program execution within my algorithm-based artifact.

In database systems, I gained experience working with both relational and NoSQL databases, including MongoDB. I learned how to design schemas, perform efficient queries, and integrate databases into application architectures. My database artifact demonstrates improved data modeling, organization, and retrieval efficiency.

Security and reliability were also emphasized throughout my coursework. I applied secure coding practices such as input validation, error handling, and defensive programming techniques to reduce vulnerabilities and improve system robustness.

In addition, I developed communication and collaboration skills through code reviews, documentation, and technical explanation exercises. These experiences strengthened my ability to communicate technical decisions clearly to both technical and non-technical audiences, which is essential in professional software development environments.

Overall, this ePortfolio demonstrates my ability to integrate multiple areas of computer science into cohesive solutions. It includes three primary artifacts: a software engineering application (Travlr Getaways), a MongoDB database system, and an algorithms/data structures project. Together, they reflect my readiness to contribute to real-world software development teams and continue growing as a professional in the field.
